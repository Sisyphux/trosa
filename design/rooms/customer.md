# 房间：客户详情

- 来源原型：无原型，来源是实现：分支 `agent/ui-daylight-perpage`（「客户工作区重做为一屏的日光房间」）。
- 状态：已选定，实现在分支 `agent/ui-daylight-perpage`，未发布。

## 隐喻
一屏的「日光房间」：打开客户即是一间房，光落在「最近沟通 | 一句下一步」上。安静，不留滚动长页。

## 动词
恢复客户上下文并推进：
- 回到最近沟通、读一句下一步（0 步，打开即在）。
- 记录沟通（唯一实心，1 步）。
- 切换分区（最近沟通 / 资料 / 联系人 / 文件 / 待办，键盘 1–5，`0` 回最近沟通）。
- 调整 / 完成 / 顺延这条待办（就地）。

## 空间模型
- 桌面 1440×900 一屏不出现整页滚动：顶栏就是分区导航（最近沟通 / 资料 / 联系人 / 文件 / 待办，键盘 1–5，`0` 回最近沟通）；左上是公司名与两行身份；左侧是安静的记录列；中间偏右是一句下一步和唯一实心「记录沟通」（旁「调整」「标记完成」，顺延明天 / 3 天后收为小字）；右下是四个读数（沟通记录 / 未完成待办 / 客户文件 / 联系人）；底栏是当前等待（点击即可修改）与「今天 · 上次沟通 N 天前」。
- 窄屏（≤1024px）：单栏流式，分区导航换独立一行、可横向滚动不隐藏；触屏目标 ≥ 44px。

## 招牌交互
光斑跟随记录：悬停或键盘聚焦某条记录时，光斑移过去、该行点亮并出现「编辑 · 加入本周 · 删除」。键盘等价：`Tab` / 焦点移动即点亮。触屏等价：点按点亮（不移动光斑）。减少动态与性能模式下点亮仍然成立，只是不移动光斑。

## 意外细节
底栏把「当前等待」做成一行可直接点击修改的文字，旁边是「今天 · 上次沟通 N 天前」——不用打开任何表单就能更新或回想状态，把这句常被埋在表单里的信息提升为随时可改的一行。

## 数据来源 / 接口
- 首屏：`GET /api/customers/{id}/summary`（身份、最近沟通、最近任务、资料缺口）+ `GET /api/customers/{id}/timeline?page=1&per_page=N`（最近沟通列，分页）。
- 按分区懒加载：联系人 `GET /api/customers/{id}/contacts`；文件 `GET /api/customers/{id}/files`；待办 `GET /api/customers/{id}/tasks`。
- 记录沟通：沿用 `openCommunicationConfirm`（现有确认面板事务）。
- 全部为现有接口，无 AI 预填（「AI 总结客户」等仍走现有入口，标注「AI 建议」）。
- 会话内短 TTL 缓存与 shell 预填为实现细节，不改数据语义。

## 落地前要补的缺口
- 无（本房间来源是已在分支上的实现，未新增接口或写入语义）。
- **合入冲突（已定）**：该分支未发布，与最新 main 的接口 / 样式叠层差异留到发布批次统一处理，现不单独决定。

## 状态
- 加载中 / 加载失败都在焦点位置以一行安静文字呈现（失败带「重新加载」）；请求超时 15 秒给「客户资料加载时间较长」。
- 没有下一步显示为「还没有安排下一步」，不是警告。
- 各分区各自的空态与失败互不牵连（次级区块按需加载，失败只影响该分区）。
- 未登录 / 权限 / 网络 / 服务 / 解析错误：沿用现有页面区分（404 提示可能已删除、5xx 提示服务繁忙、解析错误可重试）。
- 底栏「当前等待」保存失败回滚，不依赖重新打开。

## 禁忌
- 默认不做：把客户工作区做成长页面。理由：这是本房间要改掉的旧形态（弹窗 + 汇总条 + 标签页 + 右侧按钮栏），需要上下滚动、没有唯一焦点。
- 默认不做：出现第二个实心按钮。理由：整页唯一实心是「记录沟通」。
- 默认不做：首屏加载全部时间线 / 联系人 / 文件 / 待办。理由：首屏只读 summary + 最近沟通，其余按分区懒加载。
- 未选其它方向（一两句）：本房间没有独立原型，是 Daylight 全站语言下按页实现的一屏房间；其它页面各自提炼（Today 03 潮汐、客户列表 03 台账、Inbox 01 灯箱）。
- 突破世界默认处：无。

## 验收
- 缩略图测试：与其它房间并排时应可辨为「左记录列 + 中间一句下一步 + 右上四读数」。
- 去 logo 自检：遮住品牌后不应像通用「详情页 + 标签页」模板。
- 真实浏览器矩阵（**均未验证**）：宽屏 1440×900 不整页滚动、1280×800 / 960×760 / 768×1024 / 390×844 无横向溢出、iPad 真机触控、iPhone 真机、Safari、旧 Win10、键盘（1–5 / 0）、200% 缩放、系统级减少动态、性能模式。
- 数据状态：无联系人、无下一步、无文件、无待办、超长中英文公司名、多项逾期、加载失败 / 超时、各分区独立失败。
- 焦点环：实现时按 [`../UI_QUALITY_BASELINE.md`](../UI_QUALITY_BASELINE.md) 核对焦点环对比度（若沿用金色 `#bc9052` 焦点环，约 2.85:1，要求至少 3:1）。
- 回归：客户、联系人、沟通记录、Today、Inbox、Search、备份恢复、Sela 幂等同步未受影响；接口 / 权限 / 数据结构 / Sela 契约未改。
