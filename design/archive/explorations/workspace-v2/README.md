# Trosa · Customer Workspace 探索 v2

基准：v1 的 `04-instrument`（整屏利用、单一焦点、不啰嗦）。
这一轮四个方向都从「**一屏、一个明确焦点、极简、安静、无实物图**」出发，但**刻意彼此差异极大**：
构图、色调、字体、动效、信息组织全部不同，并且各自都带回 **「Colonnade 04 点击用户 → 进入本工作台」** 的转场。

共用数据集：四个原型使用同一份 `DATA.customer`（Acryl Innovations GmbH / № 014 / 德国 / 展示器材 亚克力 / SIGN CHINA 2026 / B+ / 下一步 2026-09-29），便于横向比较；真实实现时替换为接口数据即可。

### 01 Horizon 地平线
- 页面被一条地平线切开：上半是「状态」，下半是「动作」。
- 地平线上的刻度是**真实日期**（09/10、09/16、09/18、09/22、09/24、今天、09/29），点击任一刻度会高亮右侧对应的沟通记录。
- 焦点：巨大的衬线公司名 + 今天（琥珀、带向下光束）。下一步占据下半屏左侧，其余记录在右。

### 02 Grid 网格
- 十二栏细线贯穿全屏，标题是**当前状态**而不是公司名；「报价」用朱红强调。
- 动势是「硬切」：`clip-path` 揭示、顶栏从上落下、黑条从下升起——没有柔和淡入。
- 焦点：`确认样品反馈，/ 准备下一轮报价。` 两行巨型字。

### 03 Dial 表盘
- 唯一「仪器」隐喻：圆盘是真 SVG，30 个日刻度覆盖 09/01–09/30，苔绿弧线已发生时段的经过，琥珀指针精确指向 09/29。
- 焦点：盘心的 `09/29`。底部信号带常驻最近沟通与四项统计。

### 04 Scroll 卷
- 左侧整列是一句**竖排题字**（当前等待），下方朱印「客」+ 竖排题款；文字逐字落下后印章盖下。
- 焦点：竖排题字 + 右侧衬线大字标题；底部朱红操作条收束。

## 转场（Colonnade → Workspace）

四个转场都从 04 Colonnade 的四个色块开始：鼠标悬停/点击选中用户 → 其余色块排空（`flex-grow:0`）→ 覆盖层从该色块的颜色出发，**用一次「材质变化」完成场景切换**，而不是淡入淡出：

- **dawn**：覆盖层从用户色过渡到地平线天空，同时地平线画出来（`scaleX`）。
- **split**：覆盖层被切成 12 条竖带，交错飞走，露出网格纸面。
- **drain**：四色渐变向内收拢成三个同心环，收到盘心后指针扫动。
- **ink**：一道笔锋自上而下落下，墨迹在纸面晕开。

判断标准是**完整体验是否自然**：色块消退 → 材质变化 → 新界面元素依次就位（顺次 stagger），全程约 1.6–2.1s，可 Esc 跳过。

## 通用交互

- 顶部/侧边导航切换 **时间线 / 资料 / 联系人 / 文件 / 待办**（内容原位替换，桌面端不产生滚动）。
- 键盘：`1`–`5` 切分区，`0` 回到时间线，`Esc` 跳过转场。
- 右下角「重播转场」可重新播放当前用户的 Colonnade → Workspace 转场。
- `prefers-reduced-motion` 下直接落到最终状态。
- 响应式：1440 / 1280 / 1024 单屏并排；≤900–1024 堆叠为单列并可纵向滚动；390 宽无横向溢出。
