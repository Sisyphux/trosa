# Trosa 设计基准

> 现行 UI 基准，**以正在运行的实现为准**：外观的事实来源是 `app/static/swiss-d.css`（默认外观，2026-10-09 起），页面结构的事实来源是 `app/static/index.html` 与 `app/static/app.js`。文中数值若与代码不符，以代码为准并回来改本文。
> 与风格无关的可访问性、状态、组件行为和验收矩阵见 [`UI_QUALITY_BASELINE.md`](UI_QUALITY_BASELINE.md)。产品原则以 `PRODUCT_DESIGN_STANDARD.md` 为准。
> 2026-10-13 起，旧的 Daylight 设计规范、房间文档（`rooms/`）、探索原型（`visual-exploration/`）、灵感库（`inspiration/`）和归档（`archive/`）已删除，只在 git 历史里可查；不再有“先出原型、选定、提炼房间文档”的前置流程，改动直接对照本文和 `UI_QUALITY_BASELINE.md`。

## 1. 外观：瑞士式

白底黑字、方角、细线，一种字体，一个强调色。所有页面（今天、客户列表与详情、Inbox、日历、设置、本周工作、搜索、弹窗）使用同一套。

- **色**：黑 / 灰 / 白。`--dl-ink #111`（主文字与实心动作）· `--dl-ink-2 #444` · `--dl-ink-3 #595959`（纸面上阅读文字至少用它）· `--dl-mut #666`（只放非必要的安静标签）· 细线 `--dl-hair` / `-2` / `-strong`。状态色（danger / ok / info / warn）只表达状态，必须带文字。
- **强调色只有一个橙红**：页面顶部 4px 细线（`#e8431f`）和 Today 的“现在”线。其余装饰性红色、金色一律不用；选中态用墨色描边或墨色实心，不用橙红。
- **字体**：Hanken Grotesk 一种，中文用系统无衬线（苹方 / 微软雅黑），不用衬线与等宽；粗体只用 600（页面大标题 700）。数字用等宽数字特性。字阶沿用 `--dl-fs-*` token。
- **形**：圆角 2px；1px 细线取代卡片与边框；没有阴影（浮起的菜单、弹层只留一条细线）；没有墙面渐变、暗角、天光带与光池。
- **标签**：小号、正常大小写、不加宽字距、不用大写；斜体只用于西文辅助文字，中文不斜体。
- **焦点环**：`:focus-visible` 2px 墨色实线，外移 2px。
- **唯一实心元素**：整屏只有一个实心（墨底）主操作，通常是“记录沟通”；其余动作是文字或描边。弹层是新的一屏，可以有自己的一个实心按钮；危险操作只在最后确认一步才用危险色实心。
- **性能**：该外观本身很轻，界面性能不再分档，设置里隐藏该选项，也不因卡顿自动降级。
- **新代码**：只引用 `--dl-*` token 或语义层，不写死色值，不新增字体、色系、圆角与阴影。`?type=classic` 是临时回到旧外观的开关，不再有设计依据，也不再往它上面补样式。

## 2. 世界规则（与外观无关）

### 2.1 一屏一个焦点

每个屏幕（页面或弹层）只有一处被点亮的内容，通常是“下一步”或当前选中项；周边靠墨色深浅退到低对比，不靠加框、加色、加徽章表达层级。

### 2.2 动效

- 框架不动，被聚焦的任务可以动。位移通常 ≤ 8px；列表变化保持位置连续。
- 时长用 `--dl-dur-fast .16s`（微交互）、`--dl-dur .28s`（面板、弹层）、`--dl-dur-slow .55s`（转场）；缓动 `--dl-ease`。
- 动画只做四件事：说明来源、确认结果、保持连续、引导注意；没有装饰性持续动效。
- **持续动效的唯一例外是“等待”**：数据还没到时，等待组件（§2.6）可以循环“写字”，数据一到立刻消失；其余任何地方不得循环。描线类动画（图标出现、勾、下划线）只播一次，时长 `--dl-dur`（.28s）到 `--dl-dur-slow`（.55s），之后静止。
- 必须响应 `prefers-reduced-motion`：动画直接到终态，功能不变。任何核心操作都不能等动画播完。

### 2.3 可访问性底线

细则与验收见 `UI_QUALITY_BASELINE.md`，这里只列世界级底线：

- 正文对比度 ≥ 4.5:1，大字 ≥ 3:1；`--dl-mut` 不放必须读到的信息。
- 键盘可完成全部功能；200% 缩放时核心操作可完成；不依赖悬停获得必需信息。
- 目标尺寸：控件高度 `--dl-tap` 40px（粗指针 48px），任何点击目标不小于 36px / 触控 44px。
- 不靠颜色单独表达状态，状态必须同时有文字或图标。

### 2.4 状态完整性

每个核心页面都要区分并呈现：**加载、空、未登录、权限、网络、服务、解析错误**。失败不得显示成“没有数据”。

- 失败用错误块：文字说明 + 重试，保留已加载内容。
- 空状态回答三件事：这里是什么、为什么为空、下一步可以做什么（正文不超过两句，只一个下一步）。统一用 `emptyStateHtml(kind, title, hint, action, opts)` 出图（一张纸 + 一句话，见 §2.6）；失败不是空，仍走错误块。
- 局部刷新只加载对应区域；核心页面不等待 AI、网站读取、邮箱验证或后台任务。未配置 AI 时页面必须完整可用。

### 2.5 内容规则

- 日期：紧凑无空格，如“2026年9月29日”“9月29日”“10月15日”；近期优先“逾期 1 天 / 今天 / 明天”，详情里给准确日期；同一页面不混用格式。
- 数字用等宽数字；0 不强调；异常数字必须带解释；不用红色数字制造没有行动意义的压力。
- 按钮写具体动作（“记录沟通”“保存修改”），不写“确定”“提交”；文案按 `PRODUCT_DESIGN_STANDARD.md` §13 说人话。
- **AI 内容必须标注“AI 建议”或“AI 分析”**，事实依据在前；AI 只预填与提议，不自动创建客户、联系人、待办或商业承诺；生成失败时保留用户输入。
- 沟通记录可以没有下一步；待办必须同时有明确动作和日期。
- 公司名默认单行截断，详情中完整显示；邮箱、网址、长编号可安全换行。
- 不用 Emoji 当图标，图标统一为带可访问名称的线性 SVG（「一笔」手绘版，见 §2.6）。

### 2.6 一笔：手绘图标与等待（2026-10-14 起）

瑞士式的白底细线之上，只加一种“人写的”东西：**一笔**。它不是装饰，三件事才用它：等待时有人在写、空的时候有一张纸（二期）、动作完成时有一笔回应（三期）。

- **图标**：全站图标由 `tools/hand_icons.mjs` 用同一个确定性生成器画出（按图标名做种子），产物是 `app/static/icons/hand/*.svg`（遮罩用）、`app/static/hand-icons.js`（内联用）和 `visual-v2.css` 里的 `.ui-icon-*` 映射块。**新增图标只改生成器里的 `ICONS`**，不手改产物；`node tools/hand_icons.mjs --check` 校验产物是最新。抖动幅度 `HAND = 2.1`：16px 下仍清楚，放大一眼看出是手画的。
- **线宽分三档**（单位 viewBox，渲染约 1.4–1.6px）：16px 档 2.2、20px 档 1.85、24px 档 1.6。`uiIcon(name)` 默认 16px 档，`uiIcon(name, 'md')` 20px 档，`uiIcon(name, 'id')` 24px 档。内联图标用 `<svg class="hi" data-hand="名字">`（静态页面）或 `handIcon(name, {cls})`（脚本）。
- **浅灰片**：一块与线稿错开约 1.5px 的低透明度墨色（`currentColor` 10%），像印刷没套准。**只给“身份”位置**：导航、空状态插画、整页等待、页面或弹窗标题区；**按钮里和 ≤16px 的小图标不加**（加了发脏）。内联图标默认不显示浅灰片，加 `hi-id` 才显示；遮罩图标只有 `-20` / 24px 档文件带浅灰片。不新增颜色：浅灰片只用墨色低透明度或现有的羽毛灰 `#e4e3df`。
- **描线**：图标在出现的那一刻被画出来一次（悬停 / 键盘聚焦 / 选中 / 提示出现），之后静止。减少动态与 `html.motion-reduced` 时直接到终态。
- **等待组件**（`waitHtml(text, tier)`，样式 `.wait*` 在 `swiss-d.css`）：一个组件，三档——`inline`（一支笔写一道波浪，用于按钮、状态条）、`block`（一张纸被写满三行，用于分区、列表、弹窗内）、`page`（纸 + 羽毛笔，用于打开客户这类整页）。**超过 300ms 才出现**（CSS `animation-delay`，不靠定时器，没有动画时直接可见）；文案由调用方给，沿用具体说法（“正在读取沟通记录…”）。基础态就是“写满的样子”，所以减少动态时是静止的、不丢信息。**不再新增转圈、进度条或骨架闪烁**。
- **保存状态**：全局状态条（`#actionStatus`、`#connectionStatus`）里，处理中是笔，成功是画出来的圈勾，失败是画出来的叹号三角；提示（Toast）位移 8px，图标出现时描线。
- **空状态插画**（二期）：96×72，由同一生成器画出（手绘程度更大，`ILLUS_HAND = 4.2`），一张纸加一支笔，带一块浅灰片。种类：`inbox`、`timeline`、`todo`、`search`、`customers`、`week`、`contacts`、`files`、`day`、`log`、`clear`（新增种类只改 `tools/hand_icons.mjs` 的 `ILLUS`）。**第一次出现时描一遍，之后重新渲染都静止**（`emptyStateHtml` 记住画过的种类）。窄列或已有大标题的位置用 `compact`（小图、左对齐），列表侧栏用 `noArt`（只有文字）。文案不超过两句，按钮写具体动作。
- **边界**：不新增颜色、字体、阴影、圆角；橙红只在现有位置；登录柱廊不动；对比度、键盘、200% 缩放和触控尺寸不退步；图标保留可访问名称（装饰性图标 `aria-hidden`，不装饰的带 `aria-label`）。

## 3. 页面结构（现行）

每个页面的结构是确定的；改动在这个结构内做，不在页面里再发明另一套视觉。

| 页面 | 结构 | 要点 |
|---|---|---|
| **今天（潮汐）** | 上方一条潮线：横轴是我们这一天的 00–24 点，曲线是每一刻有多少位对方在工作时间（对方当地 09–18、周一至周五），一条“现在”线贯穿潮线和下方表格。每个客户一行：名字与下一步、对方工作窗口投到我们这一天的窗口带、状态与倒计时。行分三组：窗口已开 → 稍后开窗 → 今天没有窗口；没有时区的客户单独放“时区未知”。 | 点或拖潮线预演任意时刻，整张表按那一刻重排（`←` `→` 步进 30 分钟，`Shift` 3 小时，`Home` / `Esc` 回到现在）。右栏是“接下来 14 天”与折叠的“本周记录”。窄屏（≤820px）单栏，潮线退化为装饰。顶部有“N 条对话等你回复”入口，没有对话时不出现。待办只有日期没有时刻。 |
| **Inbox（对话）** | 入口始终打开与 sela 的对话：左侧对话列表（已归档默认折叠），右侧消息与回复框。 | 没有按问题类型生成的表单；不可逆动作走对话里的确认消息。“其他事项”页签（客户回复捕获、待确认主体等）只在确实有内容时出现，其内容一次放亮一条、下方是按到达顺序的条带，来源原文里的数量、价格、日期、交期自动高亮（`H` 开关）。 |
| **客户列表（账页）** | 一条纵向长卷，按“最近发生”分段（今天、昨天、本周、本月、一至三个月、更早、尚无记录）。每条两行：公司名靠左、距今靠右、中间点线；第二行国家·来源 · 行业 / 最近沟通 / 下一步。左边距“书眉”随滚动显示当前分段与小计，右侧刻度尺代表整卷。 | 只渲染可视区附近条目；视图按钮显示各视图数量；键盘方向键、PageUp/PageDown、Home/End、数字键 1–6 切视图。窄屏刻度尺缩小，“打开客户”移到底部栏。 |
| **客户工作区** | 打开客户即一屏：顶栏是分区导航（最近沟通 / 资料 / 联系人 / 文件 / 待办，键盘 1–5，`0` 回最近沟通），中心是“最近沟通 | 一句下一步”，底栏是可直接点击修改的“当前等待”。 | 首屏只读摘要与最近记录，其余分区按需加载；“记录沟通”是唯一实心。窄屏单栏。 |
| 日历、设置、本周工作、搜索、弹窗 | 同一套外观词汇：纸面与细线、小标、文字动作加一个实心按钮、读数、错误块与空状态。 | 完成跟进弹窗：打开即聚焦“这次发生了什么”，`Cmd/Ctrl+Enter` 提交，失败保留内容。 |

数据来源与写入语义见各接口与 `AGENTS.md`；页面结构变化不得改变客户、联系人、沟通记录、Today、Inbox、Search、备份恢复或 Sela 幂等同步的行为。

## 4. 验证

- **去 logo 自检**：遮掉 logo 与品牌名，页面是否仍不像通用 SaaS 后台？
- **评审与创作分离**：评审对照本文和 `UI_QUALITY_BASELINE.md`，在真实浏览器按矩阵验收（宽屏、iPad、iPhone、旧 Win10、键盘、200% 缩放）。界面缺陷按 `docs/REAL_BROWSER_REPRO.md` 先重现再修。
- **改外观**：先改 `swiss-d.css` 或 token，不给单个页面另写一套颜色、字体、圆角；改完跑 `python3 tools/check_daylight_contrast.py`（对比度检查，名字沿用旧称）。
