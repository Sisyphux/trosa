# Customer Workspace v3 — 四个新的结构假设

v2 的四张被否掉了：01 的地平线想法成立但没被用起来，04 太普通，02/03 太杂乱。
所以 v3 不换配色重做，而是**换结构假设**：每张都由一个"页面为什么长这样"的命题长出来，
其余一切（分栏、字体、动效、信息组织）都为这个命题服务。

四张共用同一份客户数据（Acryl Innovations GmbH，今日 2026-09-27），
都用一屏承载（桌面 1440×900 无滚动），都自带「从 04 Colonnade 点击用户 → 进入工作台」的转场。

| 方案 | 结构假设 | 构图 | 主色 | 字体 | 转场 |
|---|---|---|---|---|---|
| **01 Meridian 地平线** | 地平线就是时间轴，名字坐在线上 | 上 46% 天光 = 状态，下 54% 台面 = 动作；线上一排可交互日期刻度 | 暮色渐变 `#222A34→#8E8C84` + 骨白 `#EFEAE1` + 琥珀 `#B5743C` | Instrument Serif + Inter | **sunrise** — 光从地平线升起，名字落定 |
| **02 Plinth 展台** | 美术馆式留白，墙签即界面 | 中央一件"展品"（下一步），一块铭牌，底部一整条目录式展开 | 展墙白 `#FAF9F6` + 墨 `#1C1C1B` + 赭石 `#A8763E` | Fraunces + Inter | **mount** — 色块收拢成墙上那块铭牌 |
| **03 Light 光** | 暗房与一束光，光跟着注意力走 | 近黑房间，左下一列安静的沟通记录，右侧一束暖光里只有"下一步" | 房间 `#17150F` + 光 `#F2E7D3` + 暖琥珀 `#D2954F` | Newsreader + IBM Plex Mono | **ignite** — 暗下去，光在房间里亮起 |
| **04 Two Voices 对白** | 关系是两个人的对话 | 左列客户 / 右列我方，中间一条脊柱，一行一句话 | 冷暖双栏 `#E7E3DA` / `#F1EEE7` + 石板蓝 `#5A6B7A` + 陶土 `#9A6A4C` | EB Garamond + Inter | **open** — 色块像书一样从中间翻开 |

## 每张的关键点

**01 Meridian** — 公司名用超大衬线，**基线正好落在地平线上**；地平线上一排真的是日期刻度
（9/10、9/16、9/18、9/22、9/24、今天、9/29），刻度从线里向上淡出。悬停任一格会浮出那张沟通记录卡，
点击同时高亮下方对应行。天光偏暖/偏冷用来表达"多久没联系"。

**02 Plinth** — 页面故意极空。只有一件被"展出"的东西：下一步。一根 1px 细杆托着它，
顶部一个赭石点。最近沟通做成展签（label + 斜体引文 + 署名）。底部是整页唯一的密集区：
一条目录式横向展开，切分区时它的栏目跟着变。右侧竖排导航像美术馆的墙上目录。

**03 Light** — 全屏近黑，只有一束光。光**跟随鼠标**缓慢移动（lerp，约 1.2s 跟随），
悬停左侧任一记录时，光会移到那一行并把它照亮。整页只有"记录沟通"是实心控件。
暗房里唯一的亮处就是你现在该做的事。

**04 Two Voices** — 客户的话进左栏（冷灰、斜体衬线），我方的话进右栏（暖纸、无衬线），
展会现场那种双方发生的事横跨中线。中间的 1px 脊柱在进入时从上向下画出。
切到资料/联系人/文件/待办时，两栏合并成一栏（对话结束，回到档案）。

## 转场（Colonnade → Workspace）

四张都从 Colonnade 的四道色栏开始：悬停选中一个用户，其余色栏收拢消失，
覆盖层开始做一件**与页面结构同源的事**，而不是简单交叉淡化：

- Meridian：一道光从地平线升起，色块褪成天光与台面
- Plinth：色块收成一块铭牌（正是页面上那块标签的位置与尺寸）
- Light：房间暗下来，一束光在其中亮起
- Two Voices：色块像书页一样从中缝向两侧翻开

约 1.6–2.1s；`Esc` 立即跳到终点；`prefers-reduced-motion` 直接落终态。

## 本地查看

```bash
cd <repo>
python3 -m http.server 8799 --bind 127.0.0.1
# 打开 http://127.0.0.1:8799/design/visual-exploration/workspace-v3/index.html
```

`index.html` 是四宫格对比页：可切 Desktop 1440×900 / iPad 1024×768 / iPhone 390×844，
可"重播全部转场"，也可单独打开某一张。

按键：`1`–`5` 切换分区（时间线/资料/联系人/文件/待办），`0` 回到时间线，`Esc` 跳到转场终点。
右下角"重播转场"可重看进入动画。

## 响应式

1440 / 1280 / 1024 单屏不滚动；≤1024 竖排导航改为横排；≤900 纵向堆叠、允许页面滚动；
390 无横向溢出（四张均实测 `scrollWidth == clientWidth`）。
