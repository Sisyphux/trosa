# Trosa · Customer Workspace 探索 v4

这一版不是"再加四个方向"，而是**把已经喜欢的东西融合成两个方向**：

- **01 Meridian 的地平线**（地平线是真实时间轴）→ 融进 **02 Plinth 的美术馆墙签**
- **03 Light 的光线引导注意力**→ 换成**日光（亮色）**，不再用黑色房间

两个原型都是**一屏**（桌面 1440 不滚动）、共用同一份客户数据（Acryl Innovations GmbH），
都自带「从 04 Colonnade 点击用户 → 进入工作台」的转场。

## 01 Wall 展墙 · 要点

- **地平线 = 时间轴**：`.hline` 一条 1px 横线横贯墙面（上限 9/08，下限 10/16），
  每个沟通日期是线上一个刻度，标签两级交错避免碰撞；`今天` 与 `9/29` 是高刻度，
  两点之间是一段 2px 的赭石 `.runway`——**"距离下一步还有 2 天"是画出来的，不是写出来的**。
- **展签**：`.object` 悬在轴上（`.stand` 一竖线从轴升上来托住它），
  内容是下一步那句话 + 一行 `9 月 29 日 · 周二 — 2 天后 — 当前等待 · …` + 三个文字动作。
- **悬停刻度 → 档案卡**：把该条沟通的 类型 · 日期 · 来源 + 原文 + 结果 落进墙面下半部的留白里；
  点击刻度同时切到该分区并高亮底部对应的格子。移开鼠标，墙面恢复干净。
- **底部图录长条**：`.band` 把 时间线 / 资料 / 联系人 / 文件 / 待办 用同一套格子并排陈列，
  切换分区不动上面任何东西。

## 02 Daylight 日光 · 要点

- **光就是注意力**：`.pool` 是一片模糊的暖白光，静止时落在右侧焦点上；
  鼠标移动时以每帧 0.055 的插值缓慢跟随（“光比手慢一点”），离开房间回到焦点。
- **照到哪，哪就清楚**：悬停左侧任一沟通记录，光会移过去，同时那一条被"点亮"
  （底色变白、日期转金、正文变墨）；其它条目保持低对比——**明暗差就是信息层级**。
- **只有一个实心元素**：`记录沟通` 是整页唯一的实心按钮，其余都是文字动作。
- 两处光源：顶部 `.sunband`（天光从上方下来）+ 移动的 `.pool`（落在工作上的那束光）。

## 共用交互

- 分区：`时间线/最近沟通`、`资料`、`联系人`、`文件`、`待办` —— 桌面原地切换，不产生滚动。
- 键盘 `1`–`5` 切分区，`0` 回到第一个分区，`Esc` 直接跳到转场终点。
- 右下角 `重播转场` 可重看 Colonnade → 工作台的整个过程。
- `prefers-reduced-motion` 下所有动画直接到终态。
- 1440 / 1280 / 1024 单屏；≤1024 竖栏导航变为横排；≤900 堆叠；390 无横向溢出。

打开 <http://127.0.0.1:8799/design/visual-exploration/workspace-v4/index.html>
