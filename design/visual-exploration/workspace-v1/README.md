# Trosa · Customer Workspace 探索 v1

四个**彼此独立**的客户工作台方向。它们没有共同的设计系统，也不是 Colonnade 登录页的延续——
Colonnade 只是登录页当前最好的方案，不是 Trosa 的设计模板。

共同约束：低饱和、安静、极简、无实物图片、不像普通 CRM 模板、可长期高频使用；
都基于同一份客户数据（Acryl Innovations GmbH / №014），并各自设计「从 04 Colonnade 点击用户 → 进入本工作台」的转场。

打开 [`index.html`](index.html) 可并排查看四个方向的实时页面（可切换 Desktop 1440 / iPad 1024 / iPhone 390）。

| # | 名称 | 构图 | 主色 | 字体 | 转场概念 |
|---|------|------|------|------|----------|
| 01 | **Folio** 纸上长卷 | 单栏阅读，装订成册 | 暖纸 `#F3F0E8` / 墨 / 陶绿 | Fraunces + Inter | **wash** 色块漂白成纸，大标题落位 |

## 每个方向的要点

- **01 Folio**：客户就是封面。页首是衬线大标题与身份行；「现在 / 下一步」是两枚纸条；
  时间线作为正文段落，左侧有一条日期边注轨，右侧一条陶色书签带标出下一步。
- **02 Ledger**：夜间的账本。左侧固定索引栏（身份 + 分区 + 当前等待 + 用户），
  右侧横格账页，每条沟通是一行账目，右侧留白挂「结果」；底部常驻「记一笔」输入条。
- **03 Broadsheet**：今天头版。报头一句话概括当前状态，其下三条竖线分栏（资料 / 时间线 / 下一步与待办），
  首条沟通有首字下沉，日期用 Space Mono 电头。
- **04 Instrument**：近乎空白的仪表台。中央一根垂直时轴，沟通是轴上的刻度，
  最新一条是铜色节点；右侧分列读数（最近沟通 / 当前等待 / 下一步）；
  底部「近三周沟通信号」条用密度柱显示沟通节奏，铜柱指向下一步。

## 关于转场

判断标准不是两张静态截图是否相像，而是**完整体验是否自然**。
四个转场都从还原 Colonnade 的动作开始（四个色栏、悬停加宽、点击展开），
随后用各自的语言把「登录色块」变成「工作台材质」：

- 色块 → 纸（Folio）／墨（Ledger）／报头（Broadsheet）／刻度（Instrument）。
- 每个页面加载时自动播放一次，右下/左下角「重播转场」可再看；`prefers-reduced-motion` 时直接进入终态。

## 查看方式

静态文件，直接双击打开即可；或在本目录起一个本地服务（Google Fonts 需要联网）：

```bash
python3 -m http.server 8799
# 然后访问 http://127.0.0.1:8799/design/visual-exploration/workspace-v1/index.html
```

键盘：`1–5` 切换分区，`Esc` 重播转场/返回。
