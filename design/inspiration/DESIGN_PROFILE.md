# Trosa 设计画像：Daylight

> 一页读懂现行审美的气质与分工。规则、token、动效底线与验收矩阵以 [`../DESIGN_WORLD.md`](../DESIGN_WORLD.md) 为准，质量底线见 [`../UI_QUALITY_BASELINE.md`](../UI_QUALITY_BASELINE.md)。本页只回答「它像什么、为什么这样选」，不复制规范正文。

## 一句话

一束日光落在安静工作桌上的一处焦点，其余全部退到低对比——一屏只照亮「此刻该做的事」。

## 气质

- 安静、精确、可信，像清晨整理干净的工作台，而不是仪表盘或宣传页。
- 温暖而非冷灰：米白的墙、纸面的墨色；克制而非冷淡——层级由明暗差和 1px 细线承担，不靠装饰。
- 带编辑式的分寸：衬线只用于身份与焦点，正文保持清晰的无衬线扫描节奏。

## 材质

- 只有三种：**墙**（房间背景，带天光）、**纸**（阅读面）、**墨**（文字与唯一实心动作）。
- 玻璃、新拟态、厚重浮雕、整屏重阴影都不属于这个世界；临时层靠纸面浮起 + 1px 细线 + 轻阴影区分。
- 新代码只引用语义层或 `--dl-*` token，不写死色值。

## 光的语言

- **光即注意力**：一屏一个焦点，光落在「下一步」或当前选中项上。
- **光比手慢一点**：精细指针设备上光池缓慢跟随，悬停记录时移过去；这是唯一允许的持续动效，触屏、减少动态与性能模式下关闭后页面仍须完整可读。
- **金色只表达位置与顺序**（当前、悬停、聚焦、下一步日期），不做装饰，不表示好/坏或类别。

## 字体角色

- **Newsreader（衬线）**：身份与焦点——页面标题、客户名、焦点句、读数数字。
- **Inter（无衬线）**：正文与数据，数字用等宽数字特性。
- **结构小标**（大写宽字距）只标注「这一块是什么」，不承载用户必须读到的内容。

## 世界 + 房间的分工

- **世界全站固定**：光、材质、字体、动效底线、状态完整性——同一栋楼。
- **房间每页可不同**：空间模型、隐喻、构图、招牌交互可以完全不同，但不得引入新材质（新色系、新字体家族、玻璃、重阴影）。差异来自「怎么摆」，不是「换一套皮」。
- 演变路线固定在流程里：**探索 → 独立 HTML 原型 → 人选定 → 提炼 `rooms/<页面>.md` → 实现**；规范跟着被选中的原型走。

## 新意预算

- 每页 = **一个**空间模型变化 + **一个**招牌交互 + **一个**「意料之外但有用」的细节，其余全部使用共用词汇。
- 新意放在**定位、上下文、反馈**上，不放在「完成这件事需要几步」上；预算是上限，不是配额，没有合适的新意就不要硬加。

## 怎么用这一页

- 选题或评审时，先对照本页的气质与材质边界，再回到 [`../DESIGN_WORLD.md`](../DESIGN_WORLD.md) 核对具体规则。
- 与 Daylight 冲突的旧素材不作为依据；旧的暖质编辑式规范已归档在 [`../archive/`](../archive/)。
