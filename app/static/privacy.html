sela 隐私权政策

最后更新：2026-10-03

sela 是 Trosa 团队内部使用的业务助手，用于在人工授权下通过 Gmail 向潜在客户发送开发邮件，并识别回信与退信。sela 不是面向公众的应用，仅由运营者本人授权使用。

1. 我们访问的 Google 用户数据

  • gmail.send：以授权账号的身份发送 sela 生成的业务邮件。
  • gmail.readonly：只读取与 sela 已发出邮件相关的线程，用于识别客户回信和退信。

2. 数据如何使用

上述数据只用于向用户提供发信、回信/退信识别这两项功能。识别出的回信与退信状态会同步到运营者自己的 Trosa 工作区，由人工跟进。我们不会将 Google 用户数据用于广告、用户画像，也不会用于训练通用的人工智能或机器学习模型。

3. 数据存储与保护

授权凭证（refresh token）仅保存在运营者本机的 macOS 钥匙串中，不写入日志或文件。sela 不在其服务器上集中存储邮箱内容。

4. 数据共享

除上述同步到运营者自己的 Trosa 工作区外，我们不会出售、出租或向任何第三方披露 Google 用户数据，法律要求的情形除外。

5. 撤销授权与删除

你可以随时在 Google 账号的“第三方应用和服务”中撤销 sela 的访问权限。撤销后 sela 无法再访问你的 Gmail 数据；如需删除已同步到 Trosa 的记录，请通过下方邮箱联系。

6. Google API 服务用户数据政策

sela 对从 Google API 获得的信息的使用和转移，遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

sela Privacy Policy

Last updated: 2026-10-03

sela is an internal business assistant used by the Trosa team. With human authorization it sends prospecting emails through Gmail and detects replies and bounces. It is not a public-facing app.

Data accessed. gmail.send to send emails the operator authorizes; gmail.readonly to read only the threads related to emails sela has sent, in order to detect replies and bounces.

Use. Google user data is used only to provide these two features. Reply and bounce status is synced to the operator's own Trosa workspace for human follow-up. We do not use Google user data for advertising or profiling, and do not use it to train general AI/ML models.

Storage. The OAuth refresh token is stored only in the operator's local macOS Keychain. sela does not centrally store mailbox content.

Sharing. Apart from syncing to the operator's own Trosa workspace, we do not sell, rent or disclose Google user data to third parties, except as required by law.

Revocation. You can revoke access at any time at myaccount.google.com/permissions. To request deletion of records synced to Trosa, contact hamid.luo.pronamax@gmail.com.

sela's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
