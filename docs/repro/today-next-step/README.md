# 今天页无法顺手安排下一步

- 现象：在「今天」点「记录沟通」，对话框（完成并记录）只能写这次发生了什么；保存后待办完成，客户就没有下一步了，想安排下一步只能再打开客户页另建待办。
- 根因：记录沟通对话框没有下一步字段，`saveInboxReply` 把 `next_task` / `next_follow_up` 固定写成空。后端 `/api/reminders/<id>`（完成并记录）和 `/api/customers/<id>/follow_history` 本来就支持同一次写入里创建下一步。
- 修复：对话框加「下一步做什么？」+ 7 / 15 / 30 天快捷日期 + 日期框（可留空）。动作和日期都填才创建待办，只填一半会内联提示、不保存；按钮随之变为「保存并安排下一步」。AI 整理给出下一步建议时可一键填入（带「AI 建议」标记）。代理提案确认不显示这一块。同一对话框也用于 Inbox 和客户页的「记录沟通」，一并受益。
- 重现脚本：`tools/repro_today_next_step.cjs`
  - `before/`：修复前代码，退出码 20（对话框里没有下一步字段）。
  - `after/`：修复后，退出码 0（7/7：字段可见、7 天快捷日期、按钮文案、待办已创建且日期正确、原待办完成、再次打开清空、不填下一步只存记录）。`05-record-dialog-375.png` 为 375px 宽，无横向滚动。
