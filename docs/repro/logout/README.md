## 现象

导航里只有“切换账号”。点了会显示账号选择，但服务器上的登录并没有结束：再调 `/api/auth/me` 仍是已登录，办公网外刷新页面会直接回到刚才的账号。共用电脑时，下一个人刷新一下就进了上一个人的账号。

## 修改

- 同一个按钮按状态显示：已登录时叫“退出登录”，点了先请求 `POST /api/auth/logout` 结束服务器上的登录，成功后才回到账号选择；失败时提示“退出没有成功”，不假装已退出。只看周报、未登录时叫“登录”，点了会先顺手结束服务器上可能残留的登录（办公网里刷新后总是先进周报，原来的登录还在），再进入账号选择。
- 宽屏 1440px 与手机 375px 都已在真实浏览器里验证，见 `after/` 截图。
