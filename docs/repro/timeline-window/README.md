# 补记较早日期的沟通后时间线把它挤掉

- 重现脚本：`tools/repro_timeline_window.cjs`（客户已有 5 条日期靠后的记录，用“记录沟通”补记 2026-10-20 一条）。
- before：退出码 20，服务端已存，但时间线保存几秒后仍只有 3 条旧记录。
- after：退出码 0，补记那条留在按日期应在的位置（时间线读到它为止）。
- 根因：时间线按沟通日期倒序、客户页只读最新 3 条；保存后的读回按 3 条一页，日期不在最新 3 条内的新记录被挤掉。
- 修复：`refreshCustomerTimeline` 带 `ensureKey`，要保证的那条没出现且还有更多时，页宽依次放宽到 10 / 20 / 50 重读。
